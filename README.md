# create-ilha

> The official project scaffolding tool for Ilha.

Create a new Ilha application in seconds with modern templates, sensible defaults, and an interactive CLI.

## Features

- 🚀 Create new Ilha projects instantly
- 📦 Multiple project templates
- ⚡ TypeScript-first
- 🎨 Optional styling presets
- 📁 Clean project structure
- 🔧 Package manager detection
- 🌐 Cross-platform (Windows, macOS, Linux)
- 🔄 Git initialization
- 📥 Optional dependency installation

## Installation

Using npm:

```bash
npm create ilha@latest
```

Using pnpm:

```bash
pnpm create ilha
```

Using Bun:

```bash
bun create ilha
```

## What you'll be asked

- Project name
- Template
- TypeScript or JavaScript
- Package manager
- Git initialization
- Install dependencies
- Start development server
